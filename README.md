# To-Do List App

Um aplicativo simples de lista de tarefas feito com HTML, CSS e JavaScript puro.

## Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- As tarefas são salvas no `localStorage` (persistem ao recarregar a página)

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/fake_project_1.git
   ```
2. Abra o arquivo `index.html` no navegador.
